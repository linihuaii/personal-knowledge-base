## 完成内容

- 处理流程改为真实调用配置的 Ollama 嵌入客户端；校验向量条数、768 维和配置指纹。索引清单的模型名取自 `OLLAMA_EMBEDDING_MODEL` 对应配置，发布前核验现存 READY/INDEXING 片段指纹。
- 文档进入 `INDEXING` 后才发布索引，索引成功后才转为 `READY`。发布/最终状态更新失败时清理未完成片段并重建索引；重建也失败时保留 `PROCESSING` 供启动恢复。启动时先将中断的 `INDEXING` 恢复为 `PROCESSING` 并从数据库重建索引，再恢复处理中和删除中的文档。
- 删除在文档锁内执行，先标记 `DELETING`，清理文件和片段、发布索引后才标记 `DELETED`；删除失败记录 `DELETE_FAILED`，可重试，进程中断后可继续删除。
- 对上传体积设置 50MB 上限并映射超限错误为 413；校验 PDF 文件头和 DOCX 包结构，解析后拒绝空文本。
- 完成知识库编辑、带确认删除、文档筛选/预览/下载/删除/重试和处理状态自动刷新。
