## 根因与修复

`backend/pom.xml` 将 Apache PDFBox 3.0.5 声明为 `test` scope。测试 classpath 因此能够加载 PDFBox，S04 集成测试中的 PDF 通过；生产运行时 classpath 和 Spring Boot 可执行 JAR 却缺少 `pdfbox-3.0.5.jar`。Tika PDF parser 无法抽取正文，上传文档转为 `FAILED_RETRYABLE / EMPTY_TEXT`。

将 PDFBox 改为正式运行依赖。增强四格式自动测试：不仅检查预览文本非空，而且必须包含每个样例中预期的正文标记，防止只解析出元数据导致误通过。
