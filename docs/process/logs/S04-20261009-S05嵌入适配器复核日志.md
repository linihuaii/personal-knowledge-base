## 变更范围与理由

S05 将原专用 `OllamaEmbeddingClient` 替换为 `ModelGateway` 的嵌入接口，使 S04 上传、重试、重启恢复、索引重建共用当前独立配置的 Ollama/OpenAI 兼容嵌入模型。文档片段、向量、索引清单和查询侧依靠 provider/model/dimension 指纹保持兼容。嵌入配置变化触发全库重建。

针对未明确保存的公共嵌入默认配置，恢复时将 PROCESSING 文档与旧指纹 READY 文档置为 `FAILED_RETRYABLE` 并给出确认错误，防止重启隐式将本地文档发送到公共服务；模型设置显式保存、页面再次确认后，可重试或重建。

相关实现：`LibraryService.java`、`ModelGateway.java`、`ModelSettingsService.java`、`ModelSettingsController.java`、`S04DocumentWorkflowTests.java` 与 `UnconfirmedPublicEmbeddingRecoveryTests.java`。完整阶段变更列于 [S05 执行日志](S05-20261009-执行日志.md)。
