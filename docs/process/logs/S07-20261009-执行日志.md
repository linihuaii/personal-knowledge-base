## 完成内容

1. 新增 Flyway V10，持久化练习会话、题目、来源快照和答案/评分。题目来源保留摘录，资料被删除后历史仍可复习。
2. 新增练习 API 与服务：按知识库 READY 文档及当前活动索引筛选资料，支持全库或指定文档范围、单选/判断/简答、简单/中等/困难和 1–20 题配置。
3. 结构化题目逐项验证题数、类型、题干、选项、答案、解析和 chunk 归属；单选强制 4 个不同选项与 A–D 答案，判断限定 TRUE/FALSE，来源须属于当前范围。失败进行一次模型修复；仍无效不创建会话。
4. 作答前 GET 只返回题干、选项和来源，完全不返回答案、解析或评分字段。提交时校验答案集合及格式，在事务内先锁定会话状态并保存全部答案，防止并发重复提交/部分写入。
5. 单选和判断由服务端确定性判分。简答调用生成模型按参考答案辅助评分，分值 0–1；模型不可用时保留提交内容并提供待评分状态和重试接口。
6. 增加练习历史、提交后复习、错误题高亮和来源跳转；增加公共模型资料发送前确认。
7. 更新 API/Data Model 文档，并记录真实模型样题抽查和 S07 验证结果。
