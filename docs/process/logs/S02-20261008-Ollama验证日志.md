# S02 Ollama 真实连接验证日志

- 阶段：S02
- 时间：2026-10-08（Asia/Shanghai）
- 目标：验证本机 Ollama 的服务连接、模型发现、真实生成和嵌入能力。

## 环境与模型

- Ollama 客户端/服务端版本：`0.20.0`
- 服务地址：`http://127.0.0.1:11434`
- 本地生成模型：`gemma4:e2b`（5.1B，Q4_K_M）与 `gemma4:e4b`（8.0B，Q4_K_M）
- 云端模型条目：`gemma4:31b-cloud`、`glm-5.2:cloud`；本次未调用

## 验证结果

- `GET /api/version`：通过，返回 `0.20.0`。
- `GET /api/tags`：通过，成功返回模型列表。
- `POST /api/generate`，模型 `gemma4:e2b`：通过；提示要求只回答 `OLLAMA_OK`，实际返回 `OLLAMA_OK`，`done=true`、`done_reason=stop`。
- 生成耗时：总计约 12.92 秒，其中模型加载约 9.62 秒；该单次结果不是性能承诺。
- `POST /api/show`：模型能力为 `completion`、`vision`、`audio`、`tools`、`thinking`，未声明 `embedding`。
- `POST /api/embed`，模型 `gemma4:e2b`：失败，HTTP `501 Not Implemented`；证明该模型不能作为嵌入模型。

## 专用嵌入模型验证

- 选择并安装：`nomic-embed-text-v2-moe:latest`，模型 ID `ff9c2f10ef5e`，本地大小约 957 MB。
- 选择依据：面向多语言检索，适合中文知识库；官方建议查询使用 `search_query:`、文档使用 `search_document:` 前缀。
- `POST /api/embed` 批量输入：通过；3 个输入返回 3 个向量，每个向量 768 维，`prompt_eval_count=39`。
- 首次已加载请求：总耗时约 130 ms，其中加载约 70 ms；该单次结果不是性能承诺。
- 重复一致性：相同批量输入连续两次生成，最大绝对元素差为 `0.0`。
- 中文语义区分：查询“Java集合是什么？”与 Java List 文档余弦相似度约 `0.5730`，与无关 Python 字典文档约 `0.1686`；相关文档得分更高。

## 结论与影响

Ollama 本地生成与嵌入适配路径均已完成真实连接验证。生成模型固定验证为 `gemma4:e2b`，嵌入模型固定验证为 `nomic-embed-text-v2-moe:latest`、维度 768。索引指纹必须包含提供者、模型、维度和流水线版本；系统不得在本地嵌入失败时隐式回退公共 API。

本次没有输出或记录密钥，不调用云端模型。S02 可将 Ollama 生成与嵌入真实连接均记为通过。
