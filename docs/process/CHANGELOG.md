# 范围与技术基线变更记录

## 2026-10-09：S05 公共 API 真实验证人工豁免

- 原因：项目所有者明确表示“暂时不验收公共API密钥，人工放行”。
- 变更：本轮 S05 审核暂不以公共 API Key 配置、真实公共 API 请求作为放行条件；采用已完成的本机 Ollama 真实配置/连接和 RAG A1 冒烟作为真实模型证据，并保留确定性 OpenAI 兼容协议测试。
- 影响：调整 `PLAN_MASTER.md` S05/R11 的当前验收范围，仅对此次 S05 人工放行有效；不删除或改写计划的长期双接入验证要求，也不伪称公共 API 已验证。阶段日志保留该缺项及人工豁免来源。
- 验证：`gemma4:e4b`、`nomic-embed-text-v2-moe:latest` 本机连接测试通过，768 维嵌入与真实 RAG A1 结果记录于 [S05 Ollama 验证日志](logs/S05-20261009-Ollama-真实链路验证日志.md)。公共 API 仍没有真实服务证据。
- 审核：S05 转 `REVIEW_PENDING`，交独立审核。S04 通用嵌入适配仍需先复核；S05 审核不得先于 S04 复核结论批准，且本次豁免不放行 S06。

## 2026-10-08：后端运行基线改为本机 JDK 17

- 原因：项目所有者要求使用电脑已安装的 JDK；核对 `java -version` 和 `javac -version` 后确认实际版本为 17，并由项目所有者明确选择 JDK 17。
- 变更：计划、SRS、架构与 ADR 的后端基线由 Java 21 改为 JDK 17；保留 Spring Boot 3.x 路线，并要求在 S02 验证已固定的候选依赖组合。原 Java 21 专属 Lucene 候选撤回。
- 影响：R12 本地交付环境要求、S02 技术选型与兼容性验收、S03 工程搭建输入。R01–R11 的功能验收条件不变。
- 验证：本机 `java -version` 为 `17+35`，`javac -version` 为 `17`。Spring Boot 3.5 官方文档要求至少 Java 17；完整构建、Tika/PDFBox/H2 兼容性仍未验证。
- 审核：S02 保持 `CHANGES_REQUIRED`。本变更不使历史审核记录失效或自动放行 S02；后续 S02 复审须审核新技术基线。
