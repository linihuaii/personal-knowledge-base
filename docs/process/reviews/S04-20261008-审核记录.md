## 问题与处理要求（按严重程度）

1. **高：S04 核心处理与一致性未完成。** `LibraryService` 使用 `Runnable::run`，上传请求同步执行 Tika 解析；文档达到 `READY` 时只有文本片段，没有嵌入或索引。S04 计划明确要求后台解析、分段、嵌入、状态可见、失败重试及删除索引一致性，不能把必做项直接转交 S05。实现可恢复的后台任务及索引生命周期；若需调整批准过的 S02 架构或阶段边界，先记录变更并复核。
2. **高：删除与重试缺少失败一致性保证。** `deleteDocument` 先删除片段并标记 `DELETED`，随后文件删除异常被忽略；接口仍可能报告成功并留下原文件。`process` 逐片段写入后若中途失败，旧/新片段可能部分保留；`@PostConstruct` 恢复入口吞掉全部异常。设计可恢复状态和幂等清理，验证进程中断、重复重试和删除失败。
3. **高：R01/R02 页面流程不完整。** 知识库页面没有编辑/删除及影响确认，资料区没有筛选、文本预览、下载、重试或删除入口。补齐页面交互、错误/处理中状态和相应 API 客户端方法。
4. **中：缺少 S04 验收证据。** 未提交四种格式成功样例及对应测试；非法/损坏/空文本、删除后存储与索引清理、重试去重、重启恢复等计划指定场景均未验证。补充可公开自制样本、自动测试和必要的手工验证记录；未运行的检查不得记为通过。
5. **低：阶段索引的实现提交仍写 `WORKTREE`。** 当前产物已有提交 `ecc3d83`；返工后应在阶段索引和日志中记录最终待审核版本，避免审核对象不明确。
