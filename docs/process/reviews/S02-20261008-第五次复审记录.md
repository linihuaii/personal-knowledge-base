1. **高：选定解析依赖未通过最小原型。** `parse_sample` 仍以正则读取 DOCX XML 和 PDF 原始字节；即使自制 PDF 结构有效，也不能证明 Tika `3.2.2` / PDFBox `3.0.5` 的解析、页码/章节定位和兼容性。S02 计划要求解析样本文档并以原型核实关键风险。请以选定解析库运行有效样本，保存命令、版本、提取文本和定位结果。若客观条件阻止，请记录具体受阻步骤，而非将该证据转移为 S04 已可处理事项。
2. **高：锁定依赖仍缺兼容性运行证据。** ADR 列出 Java 21、Spring Boot、Maven Wrapper、Tika、PDFBox 和 H2 版本，但当前环境只有 Java 17、无 Maven，未进行依赖解析或最小构建。S02 要求核实兼容性后固定版本；请补充目标环境的实际运行记录，或明确阻碍和后续阶段风险供复审判断。
3. **中：外部模型与真实嵌入未验证。** OpenAI 兼容服务和 Ollama 请求均连接失败。此项因外部服务条件缺失可作为未验证项评估，但不得记为接入通过；S05 真实接入验收仍为硬门禁。
