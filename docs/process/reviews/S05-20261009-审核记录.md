1. **高：检索实现绕过已批准的本地索引方案。** S02 ADR-001 决定使用包含 manifest、片段映射和向量的单文件 `index-v1.json` 原子快照，S05 工作要求校验索引版本。当前检索只使用数据库向量，索引文件实际不参与问答。请接入快照读取和版本/模型/维度校验，验证缺失、损坏、旧版本及删除后不命中；若决定改为数据库直接检索，应先更新架构决策并复核 S02 及受影响的 S04 索引契约。
2. **中：真实评估范围有限。** 已有一条本机 A1 冒烟，但资料不足、跨库隔离、删除后不命中和文档指令注入仅在确定性测试中验证。按评估集补充可复现的真实模型抽查结果，并区分模型质量与程序过滤保证。
3. **未验证外部项：公共兼容 API。** 本次仓库记录了临时人工豁免，不以缺少 Key 单独构成本次退回原因；保留真实连接未验证标记，后续恢复完整双接入验收时必须补测。
