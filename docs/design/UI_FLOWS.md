# 页面结构与关键流程

阶段：S02；版本：0.1；日期：2026-10-08（Asia/Shanghai）。

## 1. 页面

| 页面 | 主要内容 | 状态 |
|---|---|---|
| 知识库 | 库卡片、创建/编辑/删除确认、处理摘要 | 空状态、加载、错误 |
| 资料详情 | 上传、筛选、处理状态、预览、下载、重试、删除 | 处理中、失败、窄屏横向安全 |
| 问答 | 库/模式选择、消息流、来源侧栏、停止生成 | 无资料、SSE 中、失败 |
| 学习计划 | 目标表单、任务列表、拖拽/排序、完成、重新规划 | 校验、生成中、保留已完成 |
| 练习 | 配置、题目、提交反馈、历史 | 提交前无答案、评分中、失败 |
| 模型设置 | 生成/嵌入分组、服务类型、测试、错误提示 | 密钥掩码、不可用 |

## 2. 关键流

```text
知识库列表 → 选择知识库 → 上传 → 处理中 → 可预览/可检索
                                      ├→ 失败 → 重试
                                      └→ 删除 → 确认影响 → 清理完成

问答页 → 选择知识库/模式 → 提问 → 检索中 → SSE token + 来源 → 完成/停止

计划页 → 输入目标 → 生成 → 编辑/排序 → 完成任务 → 重新规划未完成项

练习页 → 配置 → 生成 → 作答（无答案）→ 提交 → 判分/辅助评价/来源
```

UI 只负责展示状态，不在前端隐藏答案来承担安全边界；长文本使用可滚动区域，错误提示包含可操作的下一步。
