# 课程演示脚本（约 8–10 分钟）

## 演示前准备

- 按根目录 README 启动 Ollama、后端和前端；打开首页并确认后端状态为 UP。
- 准备一份自制、无隐私的短资料（例如 Java 集合概念 TXT），放入临时目录以便上传。
- 后端生成模型建议设置 `GENERATION_MAX_TOKENS=4096`；首次模型调用可能需要等待本地推理完成。
- 不在投影、录屏或课程材料中展示 API Key、私人文件名、真实个人资料或本地绝对路径。

## 讲解和操作顺序

### 1. 项目边界与首页（约 1 分钟）

说明这是本机单人知识库，资料和数据库不上传到项目仓库；默认仅监听本机，没有账号系统。展示首页健康状态和功能导航。

### 2. 知识库与资料处理（约 2 分钟）

1. 新建“课程演示”知识库。
2. 上传准备好的 TXT，展示处理状态从排队/处理中变为 READY。
3. 打开资料详情，展示提取文本和文档操作入口。
4. 说明首版支持 PDF、DOCX、TXT、Markdown，单文件不超过 50 MB。

### 3. 检索问答与来源（约 2 分钟）

1. 进入问答，选择刚创建的知识库和严格资料模式。
2. 提出资料中有明确答案的问题。
3. 展示回答及其来源引用，打开来源确认回答可以回到原资料片段。
4. 可选：提出资料没有覆盖的问题，说明系统会表达资料不足，而不把猜测标成引用。

### 4. 学习计划（约 1–2 分钟）

输入一个短学习目标、基础水平、未来日期和每日可用分钟，生成计划。展示任务、日期和关联资料，编辑一个任务或标记完成，并指出可调整未完成计划。

### 5. 练习与反馈（约 2 分钟）

1. 在同一知识库生成少量单选、判断和简答题。
2. 展示题目配置和来源；强调提交前 API 不返回答案与解析。
3. 提交一题正确答案和一题错误答案，查看客观题判分、参考答案、解析与来源。
4. 指出简答题反馈为模型辅助评价，而非确定性考试判分。

### 6. 工程质量与限制（约 1 分钟）

简要展示需求追踪、S08 测试报告和阶段审核索引。说明 S08 完成 Windows 干净副本验证及真实 Ollama 小样本；公共 API 完整链路仍按审核记录豁免，性能样本不代表 SLA。S09 GitHub remote 尚未配置，因此不展示虚构的线上 CI。

## 演示失败时的处理

- 模型响应慢：等待模型完成冷启动；缩小资料和题目数量。
- 结构化练习生成被截断：确认生成输出预算为 4096，再重试少量题目。
- 模型未连接：检查 Ollama 服务和模型 ID；可展示已有 S08 截图/测试证据，但要说明截图或 fixture 的验证边界。
- 网络/API 不可用：切回本机 Ollama，不要把本地演示描述成公共模型验证。
