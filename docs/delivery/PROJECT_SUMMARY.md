# 课程项目总结：智能知识库管理系统

## 项目目标

本项目面向个人学习场景，打通“导入资料 → 管理知识库 → 检索问答 → 制定学习计划 → 练习与反馈”流程。资料和运行数据默认保存在本机，不提供账号、多用户、在线协作或云托管。

## 用户与典型流程

使用者建立知识库并导入 PDF、DOCX、TXT 或 Markdown 文件。服务端抽取文本、切分并建立向量索引；用户随后可以在指定知识库中提问并核对回答来源。用户也可以填写学习目标和可用时间，生成并调整计划，再按资料生成单选、判断和简答练习，提交后查看评分、解析与资料来源。

## 技术结构

- 前端：Vue 3、TypeScript、Vite、Vue Router、Pinia、Naive UI。
- 后端：Java 17、Spring Boot 3.5.6、Maven Wrapper 3.9.11。
- 数据：H2 文件数据库和 Flyway 迁移；原始资料及处理数据写入本地数据目录。
- 模型：Ollama 和 OpenAI 兼容接口适配；生成和嵌入分别配置。S08 真实端到端抽查使用本机 Ollama。
- 工程：前后端锁定依赖、Maven Wrapper、GitHub Actions 工作流和本地环境示例。

## 工程过程与验证

项目按 `PLAN_MASTER.md` 定义的 S01–S09 阶段门禁推进。S01–S08 已有独立审核记录，需求追踪矩阵覆盖 R01–R12。S08 在 Windows 干净源码副本运行后端 40 项测试、前端 9 项测试，完成前端构建和 npm 依赖审计；另有真实 Ollama 小样本流程、浏览器主流程、响应式页面证据和单机耗时记录。自动化测试、真实模型抽查与确定性 fixture 的边界分别记录在测试报告中。

## 主要工程难点与处理

1. **解析和索引一致性：** 以文档处理状态跟踪导入过程；重试、删除、重启恢复和嵌入配置变化均通过后端服务及持久化测试覆盖。
2. **检索引用与范围隔离：** 问答按所选知识库过滤，并保留来源定位；资料不足时提供明确结果，删除资料后不应继续命中。
3. **生成内容的不确定性：** 模型输出经过结构校验；答案在提交前由 API 隔离。公共服务可能接收选定资料片段或作答内容，页面会在相关操作前提示；本地流程不会隐式回退公共 API。
4. **模型预算与设备差异：** 真实三题 Ollama 样本使用 4096 输出 token；默认 1200 曾造成样本截断。性能数字来自单机单样本，不构成其他设备或负载下的性能承诺。

## 当前限制

- 公共 API 的公共嵌入与完整公共 RAG 没有真实连接证据，沿用 S05 已审核的有限豁免；不宣称其通过。
- 学习计划 JSON 的真实供应商生成表现没有单独现场验证，确定性集成测试覆盖格式和失败处理。
- 性能测试只使用单文档、单次调用和本地 Ollama；没有高并发或大规模数据基准。
- S09 本地交付文档已整理，但 GitHub remote 未配置，因此尚无线上仓库、CI 运行链接或可核验的克隆交付结果。
